# API Documentation

## API Gateway

Base URL:
http://localhost:3000

### Health Check

GET /health

Response:
{
  "success": true,
  "message": "API Gateway is running",
  "service": "api-gateway"
}

---

## User APIs

### Create User

POST /api/users

Body:
{
  "name": "John",
  "email": "john@example.com",
  "password": "123456"
}

### Get User

GET /api/users/:id

---

## Notification APIs

### Send Notification

POST /api/notifications

Body:
{
  "userId": "123",
  "message": "Hello"
}
